## 프로젝트 소개 About the Project

**오늘의 Tutti**는 사용자 행동 데이터를 기반으로 개인 맞춤형 상품을 추천하고,  
판매자와 구매자가 모두 만족할 수 있는 통합 오픈마켓 서비스를 구축한 프로젝트입니다.

추천 시스템, 리뷰 분석, 주문 및 배송 관리 기능을 통해  
정교하고 생동감 있는 쇼핑 경험을 제공합니다.

**Today's Tutti** is a project that builds an integrated open market service,  
providing personalized product recommendations based on user behavior data  
to ensure satisfaction for both sellers and buyers.

Through a recommendation system, sentiment analysis on reviews, and real-time order and delivery management, the project
offers a sophisticated and dynamic shopping experience.

## 프로젝트 이름의 의미 Meaning of the Name

**Tutti**는 이탈리아어로 **함께**를 뜻하는 음악 용어입니다.  
오케스트라에서 모든 악기가 함께 연주되는 부분에서 유래되었으며,  
다양한 악기가 조화를 이루는 장면을 떠올리게 합니다.

이처럼 우리의 오픈마켓도  
판매자와 구매자, 다양한 상품과 스토리가 **함께 어우러지는 공간**을 만들고자 하는  
프로젝트 철학을 담아 **Tutti**라고 이름을 지었습니다.

> 다양한 소리가 조화를 이루듯 **Tutti**는 다양한 사람들이 모여  
> 생동감 넘치는 마켓 경험을 만들어가는 공간입니다.

**Tutti** is a musical term in Italian that means **"together."**
It originates from the part in an orchestra where all instruments play together,
evoking an image of harmony among diverse sounds.
Likewise, our open market embodies the philosophy of creating a space
where sellers, buyers, diverse products, and stories come together harmoniously—
hence the name **Tutti**.
Just as various sounds form a harmony, **Tutti** is a place where diverse people
come together to create a vibrant market experience.

## 프로젝트 목적 Challenge

- 사용자 행동 데이터를 활용한 **추천 서비스** 구현
- 리뷰 기반 **감성 분석을 통한 키워드 추출 및 사용자 피드백 반영**
- 다양한 **정렬/검색 기능 제공**으로 탐색 편의성 강화
- **실시간 주문 처리 및 배송 정보 관리**를 통한 이커머스 기본기 확립

- Implement a **recommendation service** using user behavior data
- Extract keywords and reflect user feedback through **sentiment analysis on reviews**
- Enhance search convenience by providing various **sorting and filtering features**
- Establish e-commerce fundamentals through **real-time order processing and delivery tracking**
